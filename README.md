# Alberta Health Workforce Intelligence Platform

An end-to-end healthcare analytics project using Python, PostgreSQL, and Power BI to analyze Alberta's nursing workforce, identify workforce pressures, and support data-informed workforce planning.

## Project Objective

Alberta's healthcare system depends on having an adequate and sustainable nursing workforce. Changes in population, workforce demographics, employment patterns, recruitment, and retention can create significant pressures on healthcare delivery.

This project explores Alberta's nursing workforce using publicly available healthcare data to understand historical trends, identify potential workforce pressures, and examine how nursing capacity may evolve in the future.

The analysis focuses on turning workforce data into insights that could support healthcare workforce planning and policy decisions.

## Key Questions

1. How has Alberta's nursing workforce changed over time?
2. How is the workforce distributed across RN, LPN, NP, and RPN professions?
3. Is Alberta's nursing workforce aging, and which groups may face greater retirement-related pressure?
4. What employment patterns exist across Alberta's nursing workforce?
5. What do workforce inflow and outflow trends suggest about recruitment and retention?
6. How does Alberta compare with other Canadian provinces?
7. How might Alberta's nursing workforce change over the next several years?
8. What impact could different recruitment and retention scenarios have on future workforce capacity?

## Analytical Approach

The project follows an end-to-end analytics workflow:

**Public Healthcare Data → Data Cleaning & Validation → PostgreSQL Data Model → SQL Analysis → Python Statistical Analysis → Workforce Forecasting → Power BI Decision-Support Dashboard**

The analysis includes:

- Data cleaning and quality validation
- Relational and dimensional data modelling
- Exploratory data analysis
- Workforce trend analysis
- Provincial benchmarking
- Demographic and employment analysis
- SQL-based analytical reporting
- Workforce forecasting
- Recruitment and retention scenario analysis
- Interactive Power BI reporting

## Data Sources

The project uses publicly available Canadian and Alberta healthcare and demographic data, primarily from:

- Canadian Institute for Health Information (CIHI)
- Government of Alberta
- Public population and demographic datasets

Where detailed facility-level operational data is not publicly available, clearly identified synthetic data may be used to demonstrate staffing and capacity analysis without representing fictional records as real healthcare data.
